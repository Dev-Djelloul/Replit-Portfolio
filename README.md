# Replit Portfolio — Chef de Projet Digital

Portfolio professionnel réalisé dans le cadre du parcours **Chef de Projet Digital** chez OpenClassrooms.

Ce projet a pour objectif de présenter les compétences, méthodologies, outils et réalisations développés tout au long du parcours de formation, en s’appuyant sur une architecture moderne connectée à Notion via API.

---

# Objectifs du projet

* Valoriser les projets réalisés durant le parcours OpenClassrooms
* Structurer une présentation professionnelle pour l’oral de fin de parcours
* Centraliser les livrables et démonstrations techniques
* Mettre en place un portfolio dynamique administrable via Notion
* Déployer une application web moderne avec une logique CMS Headless
